# Face Detection and Attendance Management System

This project detects faces using Python and marks attendance automatically.

## Features
- Face Detection using OpenCV
- Automatic Attendance Marking
- Simple and Easy to Use

## Technologies Used
- Python
- OpenCV
- Jupyter Notebook

## How to Run
1. Open face ditection.ipynb
2. Run all cells
3. Face will be detected from camera
